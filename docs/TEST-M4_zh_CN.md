# M4 手工测试用例：双端角色与「防打架」

> 包：`D:\siyuan-plugins\data-sync-siyuan\release\package.zip`（SHA256 `E83FC9F84BF94F515397ADA1C7765B61719AEB2A8A65E771C8E97A4E7F439013`）
> 前置：**两端都要装这一版并重载插件**（手机端尤其重要，见 TC-M4-07）
> 新增设置：**本机角色**（host/peer/manual）、**方向所有者**（auto/强制本机/强制对方）、**当前同步角色与方向**（刷新查看）
> 本机事实：电脑指纹 `54899d17-…`、手机指纹 `606d5c4b-…`；字典序 **电脑 < 手机 → auto 时电脑是方向所有者**（正好是常年开机那台）

## 1. 核心：拦住"双主机互推"

| 用例 | 你做什么 | 会发生什么 |
|---|---|---|
| **TC-M4-01** 双端都是 host：非所有者侧被拦 | 两端都保持默认（host）→ **在手机端**点同步（或手机端菜单里的同步命令） | 弹出**红色错误提示**：「两端都配置成了主机：按方向所有权应由「电脑名」主动同步。请在其中一端把『本机角色』改成 peer（对端：电脑名 · http://192.168.100.42:6806）。本次未传输任何文件。」<br>**判定：零文件传输** —— 对端文件 mtime 不变、进度面板不进入扫描阶段、日志出现 `Sync refused (bothHostsNotOwner)` |
| **TC-M4-02** 双端都是 host：所有者侧照常 | 在**电脑端**点同步 | 正常同步（电脑是 auto 下的所有者）——两端都是 host 也不会互相打架，只有所有者会主动 |
| **TC-M4-03** 把手机改成 peer | 手机端设置 → 本机角色 → `peer` → 在手机端点同步/自动同步 | ① 手机端**自动同步不再触发**（打开思源不推、即时同步不推）；② 手动点同步**仍可成功**（用户显式操作不被阻止） |
| **TC-M4-04** 两端都改成 peer | 两端都设 `peer` → 在任一端点同步 | 自动同步被拦：「两端都是从机、谁都不会主动发起：请把其中一端改为主机（host）。本次未传输任何文件。」；手动点仍可执行 |

## 3. 锁：心跳与提示

| 用例 | 你做什么 | 会发生什么 |
|---|---|---|
| **TC-M4-07** 锁里有心跳（旧版对端兼容） | 同步进行中，查看对端 `data\.siyuan\sync\lock` 内容 | 新版写的是 JSON：`{"instanceId":"…","nickname":"电脑","direction":"bidirectional","startedAt":…,"heartbeatAt":…}`；**每 30 秒 `heartbeatAt` 会更新**（连续看两次能发现变化）<br>旧版写的是裸指纹 —— 新版能读，且退回用文件时间判断陈旧 |
| **TC-M4-08** 冲突提示带设备名 | 两端几乎同时点同步 | 后发起的一端提示「**『电脑』正在与你同步（已持续 N 秒），请稍后再试**」——比原来的「锁已存在（N 秒）」明确得多 |
| **TC-M4-09** 长同步不被误判为陈旧 | 跑一次 **超过 5 分钟**的大同步，期间在另一端点同步 | 对端**不会**抢锁：因为锁有 30 秒心跳，陈旧判定看心跳而不是"文件超过 5 分钟"。对端只会等到锁释放或提示"正在与你同步"<br>（这条需要真·长同步才能实测，日常小同步不容易触发） |

## 6. 已知行为与限制

1. **默认角色是 host**（与旧版行为一致）。所以两端都不设置时，仍是"双 host"——但因为有方向所有权，**只有电脑会主动**，手机点同步会被拦下并提示改角色。这是刻意的引导，不是故障。
2. **旧版对端（没有 role.json）**：自动同步会被**安全拦下**（提示"对端没有声明角色…请先连一次或手动同步"），手动同步仍然可用。所以**务必把手机端也更新到这一版**。
3. **`directionOwner` 是"按对的覆盖"**：本机只记一个方向所有者设置（auto/强制本机/强制对方），没有为每一台对端分别存（计划里写的 `direction.json` 用设置项实现，语义等价）。将来若要多台对端各自不同，再拆成文件。
4. **即时同步的角色化是"守卫式"**：钩子仍然挂着，但非所有者会直接 `return`，不发起推送（效果与"只在主推端挂载"一致，改动面更小）。
5. 手动同步始终允许（除"双 host 且本机非所有者"）：**用户显式点的操作不该被角色设置吞掉**，除了会造成互推的那一种。
