M3（本版）——配对与连接管理：
 1. 生成连接二维码：本机读运行中内核的 API 密钥 → 自测通过才出码；
    地址取 conf.serverAddrs 的局域网 IP 并改写为网络伺服端口 6806，逐个自测（要与本机 instance-id 相符）
    → 只把真正可用的地址写进二维码；同时提供「复制连接文本」（无摄像头也能用）
 2. 扫码 / 粘贴接入：解析 bsync:v1:{...}（也兼容裸 JSON、以及"URL + 密钥"两行式，地址会自动修正/补端口）
    → 逐个候选地址探测（读对端 instance-id 校验身份）→ 成功后自动写入 URL/密钥、重init 同步、并跑一遍连接诊断
    - 摄像头扫码：仅当浏览器提供 BarcodeDetector 时出现按钮，否则提示用手机相机扫码后粘贴
 3. 已配对设备（一键连接）：connections.json 按【设备指纹 = 对端 instance-id】记忆，IP 变了也能找回；
    支持置顶/删除；每条显示最近成功时间与最近失败原因；密钥可选不保存
 4. 失败原因分级给出：401 密钥变更 / 超时（设备休眠）/ 连不上 / 不是思源内核 / 地址被别的设备占用
 5. 新增依赖 qrcode-generator（MIT，纯 JS，无外部服务）
